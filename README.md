Browser-only, local-first participation miner Proof of Concept.

## Quick Start
1. Download this repository.
2. Open `index.html` directly in your browser.
3. Set wallet, mining capacity, and optional pool settings.
4. Accept legal terms and click Start.

No backend and no local server are required.

## Purpose
This project is provided as a Proof of Concept for educational, research, and entertainment purposes only.

## Sample Runtime Config
- Personal wallet: your own `bc1...` address
- Mining capacity: `15%` (starter-safe)
- Eco Thermal Cap: `ON` (effective max `25%`)
- Pool mining: `OFF` to start
- iPhone/iPad overnight: foreground tab + charging + auto-lock off + low brightness

## Current Scope
- UI controls for wallet, CPU target, pool toggle, and pool allocation.
- Eco Thermal Cap option (25% cap).
- Session state visibility watchdog.
- Live runtime log with copy/export.
- Legal acknowledgment gate before Start.

This app performs real browser hashing workload and includes optional pool connectivity paths, but it is not guaranteed to be compatible with all pool implementations and is not represented as commercial/production software.

## Mobile (iPhone/iPad)
Best-effort only. Keep tab in foreground, device plugged in, auto-lock off, low brightness, and Low Power Mode disabled.

OS throttling/suspension can still occur.
